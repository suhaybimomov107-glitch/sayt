📚 Дарсҳои 1–12

01 — Фундаментҳои рақамӣ ва AI

AI (Artificial Intelligence) — зеҳни сунъӣ мебошад. Он технологияест, ки ба компютерҳо имконият медиҳад баъзе вазифаҳоро иҷро кунанд, ки одатан ба зеҳни инсон вобастаанд.

  • AI чист?
  • Маълумот (Data)
  • Алгоритм
  • Компютер ва технологияҳои рақамӣ

02 — Компютер ва системаҳо

Компютер маълумотро қабул мекунад, коркард мекунад ва натиҷа медиҳад.

  • Hardware
  • Software
  • CPU
  • RAM
  • Storage

03 — Алгоритмҳо

Алгоритм маҷмӯи қадамҳои муайян мебошад, ки барои ҳалли масъала истифода мешавад.

  • Қадамҳои алгоритм
  • Input
  • Process
  • Output

04 — Барномасозӣ

Барномасозӣ ин навиштани дастурҳо барои компютер мебошад.

  • Code
  • Variable
  • Function
  • Condition

05 — Data

Data ё маълумот яке аз асосҳои муҳимтарини системаҳои AI мебошад. AI барои омӯзиш ва таҳлил аз маълумот истифода мебарад.

  • Маълумоти сохторӣ
  • Маълумоти ғайрисохторӣ
  • Ҷамъоварии маълумот

06 — Machine Learning

Machine Learning ё омӯзиши мошинӣ як қисми AI мебошад. Система аз маълумот намунаҳоро меомӯзад.

  • Training
  • Model
  • Prediction

07 — Neural Networks

Neural Network моделест, ки аз идеяи кори нейронҳои майна илҳом гирифта шудааст.

  • Neuron
  • Layer
  • Input
  • Output

08 — Deep Learning

Deep Learning шакли пешрафтаи Machine Learning мебошад, ки аз neural network-ҳои бисёрқабата истифода мебарад.

09 — Computer Vision

Computer Vision ба компютер имконият медиҳад, ки тасвирҳо ва видеоҳоеро таҳлил кунад.

  • Image Recognition
  • Object Detection
  • Image Classification

10 — Natural Language Processing

NLP технологияест барои кор бо забони инсон. Масалан, chatbot ва тарҷумонҳо.

11 — Generative AI

Generative AI метавонад матн, тасвир, код ва дигар намудҳои контентро эҷод кунад.

12 — AI ва оянда

AI дар соҳаҳои гуногун истифода мешавад: маориф, тиб, бизнес, барномасозӣ, саноат ва ғайра.
